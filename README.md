# pythonAssignment3
## Description
This project contains two tasks:
1. Task 1: Calculate factorial of a number using recursion.
2. Task 2: Perform calculations using the Python math module.
3. ## Task 1 –Calculate Factorial Using a Function
The program asks the user to enter a number and calculates its factorial recursively.
## Task 2 – Using the Math Module for Calculations
The program asks the user for a number and calculates:
- Square root of the number
- Natural logarithm (log base e) of the number
- Sine of the number (in radians)
